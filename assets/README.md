# 演示素材

`demo.gif` 是 Windows 11 + WSL2 上的真实桌面录制：DSH Web 的极简模式开始一轮任务，用户切到空白文本编辑器，任务正常结束后由浏览器提交完成通知，Windows 显示通知卡片。

录制于 2026-10-03，DSH 版本为 `0.2.0-rc.2`。演示使用中性新对话，不包含凭证、私有路径或会话标识。浏览器通知显示的来源地址已遮挡；任务栏、准备阶段和其他窗口的切换预览已去除。添加了阶段说明字幕，并在关键画面作短暂停留，通知出现后放大右下角区域；通知标题、正文和图标保留真实录制内容。

这段 GIF 展示浏览器优先路径，不是 Windows PowerShell 保底路径。GIF 没有音轨，不用于证明提示音。Windows 保底的安装包发送测试另有验证。

原始录制、截图、帧序列和制作工具均保存在仓库外，不随项目分发。
